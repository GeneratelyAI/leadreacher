# Responsive Release Checklist

Run this checklist against the release candidate after automated responsive and accessibility checks are green.

## Devices

- Current iPhone Safari in portrait and landscape.
- Current Android Chrome in portrait and landscape.
- One compact phone near 320 CSS pixels wide.
- One tablet in portrait and landscape.
- A short laptop viewport near 1024x600 and a wide desktop.

## Public Journey

- Open and close the mobile navigation with touch and keyboard controls.
- Submit an invalid website, then submit a valid website and reach signup.
- Traverse every product-story chapter and select each channel.
- Expand and collapse every FAQ item.
- Open signup, login, privacy, terms, support email, and footer links.
- Confirm the desktop hero includes the analyzer, value proposition, trust row, scroll cue, and a hint of the next section.
- Confirm phone layouts retain all hero content in natural scroll order.

## Auth And Onboarding

- Complete signup and login with the on-screen keyboard open.
- Rotate while a field is focused; confirm the field and submit action remain reachable.
- Complete every onboarding step, including channel selection and checkout review.
- Confirm fixed actions sit above the home indicator and never cover the final card.

## Dashboard

- Open and close mobile navigation and access the date filter, account menu, notifications, and theme control.
- Visit Overview, Campaigns, Prospects, Chat, Activity, Channels, Analytics, and Settings.
- Open every mobile row detail and verify all desktop actions remain available.
- Select multiple prospects and complete or dismiss the bulk-action toolbar.
- Open a conversation, return to the list, compose a message with the keyboard open, and dismiss the keyboard.
- Scroll every intentional table region with touch and keyboard.

## Accessibility And Stability

- Test VoiceOver/TalkBack landmarks, labels, control state, and reading order.
- Test keyboard order and visible focus without a pointer.
- Test reduced motion, 200% text zoom, and 400% browser zoom.
- Confirm no horizontal page overflow, overlap, clipped text, covered content, console errors, or failed first-party resources.
