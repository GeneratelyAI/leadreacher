# LeadReacher repository guidance

## Writing style

- Never use the Unicode U+2014 em dash character in source code, user-facing copy, generated copy, tests, fixtures, comments, plans, or documentation.
- Use a comma, colon, parentheses, an en dash, or a separate sentence instead, whichever reads most naturally.
- Before completing copy or documentation changes, search the repository for the em dash character and remove any new occurrences.
