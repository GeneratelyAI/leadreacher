## UI icon standard

- Keep non-interactive icons unframed. Do not place them inside decorative rounded tiles, circles, bordered containers, or background surfaces.
- Use icon size, weight, and color to create hierarchy instead of an icon container.
- Exceptions are interactive icon-only controls, avatars, media controls, and compact status or selection indicators where the surrounding shape communicates an actionable or semantic state.
